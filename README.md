# 🏥 Animal Hospital - Webhook Log System for Roblox Executor

A completely designed and tested system for automatically logging events and statistics from the **Animal Hospital** game directly to your Discord server via webhook.

---

## 📌 Features
- 📊 **Patient Status Logging:** Real-time patient health monitoring.
- 🛏️ **Bed Assignments:** Tracking which room and bed each patient is assigned to.
- ☕ **In-Game Event Logs:** Additional notifications (e.g., coffee readiness status).
- ⚙️ **Clean Structure:** Fully formatted messages and attributes tailored for Discord webhooks.

## 🛠️ How to Use

1. Copy the code ⬇️
```
webhooka_discord = "Webhooka Discord" -- Enter Discord webhook link here
loadstring(game:HttpGet("https://raw.githubusercontent.com/quickpig9/Animal-Hospital_Log-Webhooka-Discord/refs/heads/main/Script.lua"))()
```
2. Paste it into your Executor.
3. Replace the Discord webhook URL in the designated location within the script.
4. Run the script in **Animal Hospital**!
